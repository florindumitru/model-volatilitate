# 📊 Volatility ITM Analyzer

This interactive web app built with **Streamlit** helps you analyze the probability of an option (call or put) ending **In the Money (ITM)** based on **historical volatility similarity**.

The tool identifies past periods where the stock had similar volatility to the recent market conditions, and estimates:
- **Average volatility** after a given number of days (DTE)
- **Historical ITM probability** based on price evolution
- **Theoretical ITM probability** using a simplified Black-Scholes formula
